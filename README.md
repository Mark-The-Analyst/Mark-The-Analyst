### 📊 Selected work
#### 🧬 Longitudinal Health Analytics on 3.3 Billion Records

![BigQuery](https://img.shields.io/badge/Google%20BigQuery-4285F4?style=flat-square&logo=googlebigquery&logoColor=white) ![SQL](https://img.shields.io/badge/SQL-336791?style=flat-square&logo=postgresql&logoColor=white) ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![R](https://img.shields.io/badge/R-276DC3?style=flat-square&logo=r&logoColor=white) ![Power BI](https://img.shields.io/badge/Power%20BI-F2C811?style=flat-square&logo=powerbi&logoColor=black)

Built an end-to-end analytical pipeline over 3.3 billion records and 575,000 synthetic patients to study mortality, disease burden, prescribing patterns, and healthcare utilization. Handled ingestion and transformation in BigQuery and Python, applied unsupervised machine learning in R to detect anomalous medication–diagnosis pairings, and traced each flag to its root cause. Delivered a 23-page Power BI report with drill-through from network-level anomaly flags to individual facilities. **Surfaced 1.99M dispensed units of antibiotics prescribed against viral diagnoses — 91% concentrated in a single product–diagnosis pair, narrowing a diffuse stewardship problem to one addressable prescribing pattern.**
